Shipping Hub Connector — European Logistics

Carrier labels in Odoo via Shipping Hub SaaS

Features

  • Label generation on outgoing delivery orders
  • Gateway API (TLS + HMAC) for DHL, DPD, GLS, UPS, PostNL, CTT, and more
  • Batch PDF export for warehouse teams
  • Tracking, chatter PDF attachments, inventory settings
  • UI: EN, DE, FR, IT, ES, PT, PL, NL

Configuration

Inventory → Settings → Shipping Hub Connector → API token and environment.

Delivery methods → Shipping Hub Europe → carrier code matching your portal.
